# Archived short-term memory

One file per archived batch of daily logs: `session_YYYY_MM_DD.md`.

These are the untouched originals — nothing here is summarised, and nothing
here is loaded at session start. Read one only when you need the full context
of a past conversation.

Every file should be linked from the **Archive index** in
`docs/memory/MEMORY_SHORTTERM.md`.
